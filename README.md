# Presidential Luxury Hotel Management System (PLHMS)

## 🏛️ Overview
A complete, production-ready Presidential Luxury Hotel Management System built with React.js (Vite), featuring 12 meticulously designed floors, luxury accommodations, and comprehensive hotel management capabilities.

## ✨ Features
- **12 Unique Floors**: From underground parking to rooftop infinity pool
- **Luxury Accommodations**: Standard rooms, deluxe rooms, premium rooms, and presidential suites
- **Premium Services**: Fine dining, spa & wellness, helipad services, and more
- **User Dashboard**: Reservations, billing, service requests, and profile management
- **Admin Dashboard**: Hotel-wide management, analytics, and operations control
- **Responsive Design**: Optimized for all devices
- **Smooth Animations**: Framer Motion powered transitions
- **Presidential Aesthetics**: Royal gold (#C9A44C) and luxury black (#0B0B0B) color scheme

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
