# 🎯 دليل لوحة التحكم الإدارية - Hotel Management System

## 📋 نظرة عامة

تم إنشاء **لوحة تحكم إدارية شاملة واحترافية** تتيح لك إدارة الفندق بالكامل دون الحاجة لأي تعديل برمجي.

```

```

### متطلبات الدخول:
- يجب تسجيل الدخول بحساب Admin
- Role: `ADMIN`

## 📊 أقسام لوحة التحكم

### 2️⃣ Floor Management (إدارة الطوابق) 🏢

#### الميزات الكاملة:
✅ **إضافة طابق جديد**
- رقم الطابق (Floor Number)
- الاسم (Name)
- الوصف (Description)
- رفع صورة (Image URL)
- ترتيب الظهور (Order)
- حالة التفعيل (Active/Inactive)

✅ **تعديل الطابق**
- تحديث جميع البيانات
- تغيير الصورة
- تفعيل/تعطيل

✅ **حذف الطابق**
- حذف نهائي مع تأكيد

✅ **عرض الغرف المرتبطة**
- كل طابق يعرض عدد الغرف المرتبطة به

#### كيفية الاستخدام:
1. اضغط "Add New Floor"
2. أدخل رقم الطابق (مثلاً: 1, 2, 3)
3. أدخل اسم الطابق (مثلاً: "Ground Floor", "First Floor")
4. أضف وصفاً (اختياري)
5. أضف رابط صورة (اختياري)
6. حدد الترتيب (للتحكم في ترتيب العرض)
7. اضغط "Create Floor"

#### API Endpoints:
```
GET    /api/floors         - جلب كل الطوابق
POST   /api/floors         - إضافة طابق جديد
PUT    /api/floors/:id     - تحديث طابق
DELETE /api/floors/:id     - حذف طابق
PATCH  /api/floors/reorder - إعادة ترتيب الطوابق
```

---

### 3️⃣ Room Management (إدارة الغرف المحسّنة) 🚪

#### الميزات الكاملة:
✅ **إضافة غرفة كاملة المواصفات**
- رقم الغرفة (Room Number)
- الطابق (Floor)
- ربط بطابق معين (Floor Reference) - اختياري
- القسم (Section: A, B, C, D)
- نوع الغرفة (Type: Standard, Deluxe, Suite, Penthouse)
- السعة (Capacity)
- المساحة بالمتر المربع (Size)
- السعر الأساسي (Base Price)
- السعر الحالي (Current Price)
- الحالة (Status: Available, Occupied, Maintenance, Reserved)
- الوصف (Description)
- رفع صور متعددة (Multiple Images)

✅ **تصفية متقدمة**
- عرض الكل
- الغرف المتاحة فقط
- الغرف المشغولة
- الغرف تحت الصيانة
- الغرف المحجوزة

✅ **تعديل وحذف**
- تعديل كامل لجميع البيانات
- حذف نهائي

#### كيفية إضافة غرفة:
1. اضغط "Add New Room"
2. أدخل رقم الغرفة (مثلاً: 101, 202)
3. حدد الطابق رقمياً (مثلاً: 1, 2)
4. اختر Floor Reference من القائمة (اختياري)
5. اختر القسم والنوع
6. أدخل السعة والمساحة
7. حدد الأسعار
8. أضف وصفاً مفصلاً
9. أضف روابط الصور (كـ JSON array أو مفصولة بفواصل)
10. اضغط "Create Room"

#### مثال لإضافة صور:
```
https://example.com/room1.jpg, https://example.com/room2.jpg
```
أو:
```json
["https://example.com/room1.jpg", "https://example.com/room2.jpg"]
```

## 🎯 الفائدة الأكاديمية

### لماذا هذا النظام مهم؟

1. **إدارة كاملة بدون برمجة**
   - أي شخص يمكنه إدارة الفندق
   - لا حاجة لمبرمج لإضافة غرفة أو تعديل سعر

2. **قاعدة بيانات حقيقية**
   - كل البيانات محفوظة في PostgreSQL
   - لا فقدان بيانات عند إعادة التشغيل
   - علاقات واضحة بين الجداول

3. **نظام صلاحيات محترف**
   - Admin له صلاحيات كاملة
   - المستخدمون محميون من الوصول غير المصرح

4. **واجهات احترافية**
   - تصميم فاخر يليق بنظام فندقي
   - سهولة الاستخدام
   - تجربة مستخدم ممتازة

5. **قابل للتوسع**
   - يمكن إضافة المزيد من الميزات بسهولة
   - Architecture قوية ومنظمة
