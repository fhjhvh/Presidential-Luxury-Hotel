### 🚀 كيفية تشغيل النظام

#### 1. قاعدة البيانات (إذا لم تكن تعمل):
```bash
docker start hotel-postgres
```

#### 2. Backend:
```bash
cd backend
npm start
```
الـ Backend سيعمل على: `http://localhost:5000`

#### 3. Frontend:
```bash
npm run dev
```
الـ Frontend سيعمل على: `http://localhost:5173`

### 🎯 الميزات الجاهزة للاستخدام

1. **إدارة الغرف**
   - إضافة غرف جديدة
   - تعديل الغرف الموجودة
   - حذف الغرف
   - فلترة الغرف حسب الحالة

2. **نظام الحجز**
   - الدردشة التفاعلية لجمع معلومات الضيف
   - توصيات الغرف بناءً على التفضيلات
   - عرض الطوابق المناسبة
   - عرض الخدمات الموصى بها

3. **خرائط الطوابق**
   - خرائط تفاعلية لجميع الطوابق (B2 إلى 11)
   - جميع العناصر تظهر بشكل صحيح داخل الإطار

4. **ملف المستخدم الشخصي**
   - عرض معلومات المستخدم
   - تعديل البيانات الشخصية
   - حفظ التغييرات في قاعدة البيانات

5. **نظام المصادقة**
   - تسجيل دخول/خروج
   - حفظ الجلسة
   - حماية الصفحات المحمية

### ⚡ ملاحظات مهمة

1. **قاعدة البيانات**: 
   - تعمل في Docker container اسمه `hotel-postgres`
   - البيانات محفوظة في Docker volume
   - لا تحتاج لإعادة إنشاء container عند كل تشغيل

2. **الصلاحيات**:
   - تم حل مشكلة PostgreSQL 15 permissions بشكل نهائي
   - `init-db.sql` يُطبق الصلاحيات الصحيحة عند إنشاء container جديد

3. **API**:
   - جميع endpoints تعمل بشكل صحيح
   - المصادقة تعمل على جميع الطلبات المحمية
   - معالجة الأخطاء مطبقة بشكل صحيح
